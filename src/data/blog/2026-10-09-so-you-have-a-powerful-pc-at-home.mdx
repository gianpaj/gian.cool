If you're not using it every day, you might want to save electricity and money. My tower PC still uses 20-30W on idle.

Now that coding agents can do a lot, I've been walking my dog and doing small fixes on my coding projects.
And my Ubuntu server with 1TB of SSD is much faster than my MacBook Air and I don't have to worry about the laptop going to sleep or connecting it to a charger.

I started putting this PC to sleep (which I call my RTX machine) by pressing the physical button before I go to sleep and pressing it when I want it on.
Or via this command:

```sh
sudo systemctl suspend
```

After a few times I realised I can do both remotely.
I have an always-on Jetson Nano mini computer (you can use a Raspberry Pi too) that's connected to Tailscale – private free VPN for your devices.
So when walking my dog and I want to use Claude Code, [T3 Code](https://t3.codes) or Codex, I can SSH into the Jetson Nano, and send a wake-on-lan packet:

```sh
$ cat ./wakertx.sh
wakeonlan 34:5a:60:0b:c0:24

$ ./wakertx.sh
```

_On my Android phone I use [JuiceSSH](https://www.reddit.com/r/androidapps/comments/1pqzq46/juice_ssh_delisted_december_2025/) but Termius is good too._

This wakes up the sleeping gianT\* (gianRTX).
Since this machine is also on my Tailscale network, I can then SSH and run any more powerful tasks like Claude Code or any benchmarks. And now it's actually a GitHub runner for my [startup](https://holabrisa.com).

After waking it up and shutting it down every other day, I thought there must be a better way.

_An Android App that turns on your remote PC_

```
Android app or widget
        │
        │ HTTPS: Cloudflare credentials + app bearer token
        ▼
Cloudflare Access and Tunnel (optional)
        │
        │ HTTP over the tunnel to 127.0.0.1:8787
        ▼
Always-on computer (e.g. Raspberry Pi or Jetson Nano): WakeBridge server
        │
        │ UDP Wake-on-LAN magic packet
        ▼
Powerful PC or Mac
```

_Tap widget → Sending… → Waking… → Online_

### Why not an SSH snippet or HTTP Shortcuts?

A few reasons I wanted a dedicated app + tiny Go server:

1. **Know when it's actually booted:** Sending a magic packet doesn't tell you if the machine woke up. WakeBridge's Go server probes `gianRTX`'s SSH port (`GET /status`), and the Android widget polls every 2 seconds until it flips from **Waking…** to **Online**.
2. **No always-on phone VPN needed:** Wake-on-LAN is a Layer-2 LAN broadcast, so something needs to be in my home network. Using Cloudflare Tunnel + Access means I can tap the widget over cellular data without keeping Tailscale running 24/7 on my phone battery or pressing another few buttons.
3. **Honestly, I didn't know they existed:** I thought, how hard can it be for a coding agent to build a mobile app plus the necessary machinery?

It can connect to your always-on machine via Tailscale or via Cloudflare Tunnel (not tested), so your phone doesn't have to be connected to Tailscale.

## Going back to sleep automatically

The mobile app doesn't have a **sleep or shutdown button**. I didn't want to remember to turn the PC off and we can do something better.

Instead, `gianRTX` puts itself back to sleep after **15 minutes of inactivity** using Ubuntu's `autosuspend` daemon ([my install script & config](https://github.com/gianpaj/mac-setup-script/blob/gianpaj-version/ubuntu/install-autosuspend.sh)).

Every 30 seconds, it resets the 15-minute idle timer if _any_ of these are busy:

- **CPU or GPU load** (`load > 1.0` or a custom `autosuspend-gpu-busy` check)
- **Network traffic** (`> 50 KB/s` over Ethernet or `tailscale0`)
- **Active ports & package managers** (Ollama on `11434`, Tailscale Serve on `443`, or `apt`/`dpkg`/`rsync`)
- **Active Codex turns:** an LLM agent waiting on an API call uses almost zero CPU, so a custom `autosuspend-codex-busy` script checks Codex's local control socket—active turns keep the PC awake, while an idle open chat lets it sleep.
